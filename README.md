# 프로토 분석 (proto-web2)

축구 경기의 해외 배당과 프로토 배당을 비교하고, 베팅 기록과 손실 한도를 관리하는 웹앱입니다. 작업 지침은 `CLAUDE.md`.

## 화면
- 📅 경기: 달력(날짜별 경기 수) → 그날 경기(해외 배당·프로토 배당 나란히). 프로토 배당은 직접 입력하거나 배당표 사진으로 한 번에.
- 경기 분석: 시장 확률, 승·무·패마다 덜 불리/보통/피하기와 1만 원당 평균 손익, AI(웹 검색) 핵심 정보, 기록장에 추가.
- 🧾 기록장: 이번 달 손익, 분석대로 vs 감으로 성적, 결과 입력, 직접 기록.
- 🛡 지킴이: 하루 베팅·한 달 손실 한도, 복구 베팅 경고, 상담 안내, 베트맨 자동 읽기 시험.

## 환경 변수 (Vercel에만)
- `ODDS_API_KEY`: https://the-odds-api.com 무료 키 (없으면 예시 경기)
- `ANTHROPIC_API_KEY`: AI 분석·사진 읽기 (없으면 예시 분석)
- `ANTHROPIC_MODEL`(선택): 기본 `claude-sonnet-5-5`

## 실행
```bash
npm install
npm run dev
```
